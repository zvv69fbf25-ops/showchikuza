# 運命の座席発券 — 大阪松竹座風・架空ゲーム

スマホでも遊べる、単一HTMLファイルの座席発券ドキドキゲームです。サーバーやビルドツールは不要です。

## ローカルで遊ぶ
`index.html` をブラウザで開いてください。

## GitHub Pages で無料公開して友達と共有する
1. GitHub にログインし、新しい **Public** リポジトリを作成します（例: `ticket-game`）。
2. この ZIP の `index.html` をリポジトリの一番上の階層にアップロードしてコミットします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** で `Deploy from a branch` を選び、Branch を `main`、フォルダーを `/(root)` にして Save します。
5. 少し待つと同じ Pages 設定画面に `https://あなたのユーザー名.github.io/ticket-game/` のような公開URLが表示されます。そのURLを友達に送ればOK！

## 共有について
結果画面の「友達に結果をシェア」ボタンは、対応ブラウザでは共有メニューを開きます。対応していない場合は結果テキストをコピーし、LINEなどに貼り付けられます。

## 注意
- このゲームはファン向けの非公式な架空作品です。大阪松竹座・松竹株式会社・公演主催者とは無関係です。
- 座席データは演出用の架空データで、実際の松竹座の座席表や配席を再現・保証するものではありません。
- この ZIP を作成しただけではインターネット公開されません。URL共有には GitHub Pages 等への公開設定が必要です。
